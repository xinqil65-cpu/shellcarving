# 海贝拾遗 · 青岛贝雕非遗项目展示与互动游戏网站

青岛大学商学院「海贝生花，非遗续脉」实践团 2026 年 1 月起围绕青岛贝雕（山东省非物质文化遗产代表性项目）开展的实践成果展示网站与互动游戏。

## 📁 目录结构

```
shell caving/
├── 网页展示/                      # 主站：非遗项目宣传展示网站
│   ├── index.html                 # 主页面
│   ├── style.css                  # 样式（海蓝深色系 + 纹理背景）
│   ├── main.js                    # 交互（轮播 / 浮动IP / 返回顶部 / 滚动动画）
│   └── assets/
│       ├── img/                   # 实地考察、课堂实践、作品实拍、IP形象、获奖证书
│       └── video/                 # 贝雕介绍、探访记录、自制短剧
│
├── 游戏/                          # 贝雕制作互动游戏
│   └── 贝雕游戏.html               # 入口（串联 清洗→处理→制作→作品全流程）
│
├── IP设计/                        # IP 形象「贝莹」设计稿
├── 实地探访/                      # 2026.01 青岛贝雕工艺品厂 / 艺术馆 实地考察素材
├── 教学实践/                      # 2026.07 崂山区新时代文明实践中心 文化“两创”课程素材
├── 贝雕介绍/                      # 调研报告、工艺视频、贝雕介绍素材
├── 学校获奖/                      # 商学院 2026 寒假返家乡社会实践奖项证书
├── 短剧/                          # 自制非遗短剧源文件（网站已嵌入小红书链接）
└── 报道/                          # 媒体报道原文参考
```

## 🚀 本地预览

在 `shell caving` 目录下启动本地 HTTP 服务器（根目录须为 `shell caving`，使 `网页展示` 和 `游戏` 两个兄弟文件夹能通过相对路径互相跳转）：

```bash
python -m http.server 8001
# 访问：
#   主页        → http://localhost:8001/网页展示/index.html
#   互动游戏    → http://localhost:8001/游戏/贝雕游戏.html
```

启用步骤（GitHub Pages）：

1. 仓库 → **Settings** → **Pages**
2. **Source**：选 **Deploy from a branch**
3. **Branch**：选 `main`，右边目录选 `/ (root)` → 点 **Save**
4. 推送后 1~2 分钟自动生效，页面顶部会出现绿色「Your site is live」提示。
